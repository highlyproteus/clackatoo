Clackatoo

An offline keyboard for Android with swipe typing and local voice typing. Everything runs on your phone, and the keyboard has no internet permission.

Install in four steps

  1. Download. Tap Download for Android. The file is called clackatoo.apk. If Android says your browser is not allowed to install apps, open Settings from that message and allow it for now. You can switch it off again afterwards.
  2. Open the file. Open clackatoo.apk from your browser's downloads (or the Files app) and tap Install.
  3. Turn the keyboard on. Open Clackatoo and follow its setup card, or go to Settings > System > Keyboard > On-screen keyboard, switch Clackatoo on and pick it as your keyboard.
  4. Voice and grammar (optional). Install Clackatoo Models the same way. Then tap Download next to a model in Clackatoo's Voice typing or Grammar check settings. Models are large (from about 30 MB to 742 MB), so use Wi-Fi.

Check that it is genuine

Both apps are signed with the same key. In AppVerifier, add this verification info and compare it with the app you downloaded:

io.github.highlyproteus.clackatoo io.github.highlyproteus.clackatoo.models F6:B2:5F:23:73:F8:3C:19:45:64:76:1C:06:F3:CD:D8:2E:60:11:32:D2:08:2F:73:D7:81:2D:85:73:3E:BC:8D

The first two lines are the package names, the last is the SHA-256 fingerprint of the signing certificate. Every release page also lists the SHA-256 of each APK.

Good to know

  • No internet in the keyboard. Clackatoo does not ask for the INTERNET permission, and the release build fails if it ever appears. Typing, swipe, speech recognition and grammar check run on the phone.
  • Models come from a separate app. Only Clackatoo Models connects to the network, only to download the pinned model files from Hugging Face. It checks every file by size and SHA-256.
  • No tracking on this page. No scripts, no cookies, no fonts or images from other sites.
  • Open source. GPL-3.0, based on HeliBoard.
