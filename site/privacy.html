Privacy policy

Clackatoo and Clackatoo Models
Updated 29 October 2026

Who this covers

This policy covers the Clackatoo keyboard (io.github.highlyproteus.clackatoo) and its optional Clackatoo Models companion (io.github.highlyproteus.clackatoo.models), published by highlyproteus.

The developer collects no personal data through these apps. There are no developer servers, accounts, advertisements, analytics SDKs or automatic crash-report uploads. The model download host receives network requests, as explained below.

Clackatoo: an offline keyboard

The keyboard has no INTERNET permission. Typing, swipe recognition, speech recognition, transcript clean-up and grammar check are processed on the phone. Text and audio are not sent to the developer or to a speech service.

Microphone access (RECORD_AUDIO) is requested on first use of the Voice key. Recording only runs with the voice panel visible, stops when it is hidden and can be cancelled. Audio is held in memory for processing, not saved as audio recordings. Models run in a separate isolated process with no internet access.

Keyboard settings, dictionaries, model files and enabled clipboard history may be stored locally. The keyboard does not log what you type, say or receive from a model. You can delete model files and clipboard entries in the app, clear app storage in Android settings, or uninstall to remove app-private data. Exported files are under your control and must be deleted separately.

When you type or insert text into another app, that app receives it. If you send a message, upload a document or otherwise share that text, the receiving app's privacy policy applies. Clackatoo does not prevent those apps from using the internet.

Android's keyboard-enable warning describes the sensitive access all input methods need. Clackatoo uses this access to enter text at your request. Optional contact-based suggestions, if you enable them and grant READ_CONTACTS, are processed locally, not uploaded. Dictionary permissions support local user-dictionary entries; VIBRATE supports key haptics, and RECEIVE_BOOT_COMPLETED supports keyboard initialization after a restart.

Clackatoo Models: downloads from Hugging Face

The companion has INTERNET permission to download models and, in the experimental browser, search Hugging Face. It uses HTTPS and only allows Hugging Face hosts (huggingface.co and *.hf.co). Hugging Face and its hosting infrastructure receive your IP address, requested files and repository lookups, and any search terms you enter in that browser. They can infer approximate location from your IP address and retain network and usage records according to Hugging Face's privacy policy. The developer does not receive these requests or records. Do not put private text into model searches.

The companion never receives your typed text, speech audio or grammar-check text. It receives model-download requests and transfers model files to the keyboard. Both apps must have matching signing certificates for this transfer.

Pinned catalog models are checked against exact size and SHA-256. Experimental custom downloads are checked by SHA-256 only when Hugging Face publishes one; they are not verified catalog models. The keyboard checks their format and a test load before accepting them. These checks do not guarantee model quality or trustworthy output.

FOREGROUND_SERVICE and FOREGROUND_SERVICE_DATA_SYNC keep a user-started download running with visible progress. POST_NOTIFICATIONS lets the companion display download progress and a cancel action. No notification is used for advertising. The companion deletes its temporary downloaded copy after hand-over; installed models remain in the keyboard until you delete them.

Deletion and contact

There is no Clackatoo account or developer-held personal-data database to delete. Clearing app storage or uninstalling removes local app-private data. For Hugging Face's network records or privacy rights, contact privacy@huggingface.co; Clackatoo cannot delete records controlled by that independent service.

For questions about these apps or this policy, use Clackatoo's GitHub issues. Issues are public: do not post private messages, recordings, passwords or other sensitive data. Information you choose to post there is handled by GitHub and visible to the project maintainers.

This page loads no scripts, external fonts or tracking resources. Its GitHub Pages host receives ordinary web requests under GitHub's own privacy practices.
